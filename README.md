# 🎓 Student Management System

---

## 📖 Project Overview

The **Student Management System** is a simple Python-based application designed to manage student information efficiently.

It allows users to add, view, update, search, and delete student records.

***The main purpose of this project is to make student record management simple and organized.***

💻 This project provides a digital solution for managing student information.

> 📌 A simple project for learning Python and software development.

---

## 🎯 Objectives

The main objectives of the project are:

* Store student information digitally.
* Add new student records.
* View existing student records.
* Search for students.
* Update student information.
* Delete student records.
* Practice Python programming.
* Learn Git and GitHub.

## ✨ Features

### 1. Add Student ➕

Users can add student details such as name, ID, age, course, and contact information.

### 2. View Students 👀

Displays all available student records.

### 3. Search Student 🔍

Users can search for a student using the student ID or name.

### 4. Update Student ✏️

Existing student information can be modified.

### 5. Delete Student 🗑️

Users can remove unwanted student records.

### 6. Data Storage 💾

Student information can be stored in a JSON file.

## ⚙️ Installation Steps

### Step 1: Install Python

Download Python from [Python](https://www.python.org/).

```bash
python --version
```

### Step 2: Install Git

Download Git from [GitHub](https://github.com).

```bash
git --version
```

### Step 3: Clone the Repository

```bash
git clone https://github.com/username/student-management-system.git
```

### Step 4: Open the Project

```bash
cd Student-Management-System
```

### Step 5: Install Requirements

```bash
pip install -r requirements.txt
```

### Step 6: Run the Application

```bash
python main.py
```
